PromptAhead turns the page you’re on into a portable prompt for ChatGPT, Claude, Gemini, or Perplexity. Everything stays on this device — no cloud backend, no analytics.

How you’ll use it

Manual mode is active: click the toolbar icon when you want PromptAhead. Smart mode (engagement-based invites) is coming later — no website access is requested today.

  • Manual You decide when to open the panel. Uses activeTab only.
  • Smart Coming soon — optional host access, deferred to a later milestone.

Default destination

Where should prompts open by default? You can change this anytime in Settings or on the prompt screen.

On-device Nano (later)

Gemini Nano will optionally rank page-specific directions on your device. In this milestone it’s skipped — curated suggestions work fully without a download. You’ll be able to enable Nano in a later update.
